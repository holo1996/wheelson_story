## 2026-06-21 - Image Optimization and CLS Elimination
**Learning:** Found that the main video poster asset (4.1MB PNG with 2553x1080 resolution) was significantly slowing down Largest Contentful Paint (LCP) and throwing 404 errors during local development due to an absolute path prefix. Additionally, missing explicit width and height attributes across key visual assets caused noticeable Cumulative Layout Shift (CLS) on load.
**Action:** Compressed the poster PNG to a progressive JPEG (size reduced to ~210KB, with width optimized to 1280px) and updated the paths to be relative. Prevented CLS by assigning explicit dimensions to the logo, poster, about image, and work card preview images. Removed non-standard attributes and deferred the render-blocking FontAwesome script in `<head>`.
