## 2026-06-21 - Устранение FOUC в галерее
**Learning:** Скрытие элементов через JavaScript после загрузки DOM вызывает заметный "прыжок" контента (FOUC), если элементов много. Применение класса `.hidden` напрямую в статическом HTML вместе с CSS `display: none` делает макет стабильным с момента отрисовки первого байта.
**Action:** Всегда проверять возможность декларативного скрытия элементов, которые не должны быть видны при первой загрузке, вместо использования JS-циклов в `DOMContentLoaded`.

## 2026-06-21 - Оптимизация LCP через видео-постеры
**Learning:** Использование PNG без сжатия (4.1МБ) в качестве `poster` для тега `<video>` блокирует метрику Largest Contentful Paint (LCP) на мобильных устройствах и при медленном соединении.
**Action:** Конвертировать постеры в прогрессивный JPEG с качеством 80-85% и ограничением ширины до 1280/1920px. Это сокращает вес на 90-95% без видимой потери качества на большинстве экранов.
